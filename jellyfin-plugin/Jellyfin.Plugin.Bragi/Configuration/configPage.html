Bragi

Let everyone on this server find shows and request them from Bragi, without leaving Jellyfin. Requests carry each person's Jellyfin name, and go through Bragi's approval like any other request.

Connection

Bragi's address as this Jellyfin server sees it.
An admin's key, from Settings, Account in Bragi. It stays on this server; browsers and apps never see it.

Web and mobile apps

Adds a Request button to the header and shows Bragi results under Jellyfin's own search results. Works in browsers, Jellyfin Media Player and the Android and iOS apps. Reload the page after changing this.

TV apps

Apps on TVs and streaming boxes cannot show Bragi's search. Instead, the Request library lists this week's trending shows that Bragi does not have yet. Marking one as a favorite requests it.
